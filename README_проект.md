# Кореш с гитарой — полный проект (сохранено 10.11.2026)

Сайт-визитка гитариста-вокалиста **Юрия Полякова** (Владивосток): продать себя на свадьбы, дни рождения, корпоративы, показать выступления. Стиль по структуре — [lilykerbeymusic.co.uk](https://www.lilykerbeymusic.co.uk/), цвета — только Юры.

## Как открыть
Нужен локальный сервер (иначе не работают видео и спрайт):

```bash
cd "06_САЙТ_ПЕРЕДЕЛКА_в_стиле_Lily"
python3 -m http.server 8766
```
Потом `http://127.0.0.1:8766/index.html`. Пропустить вход: `?noIntro=1`.

## Файлы сайта (06)
- `index.html` — вся страница; `lily.css` — единые стили; `prices.html` + `prices.css` — цены
- `app.js` — вход, меню, диалоги, мини-Юра, афиша; `loader.js` — загрузочный экран с нотами
- `motion.js` — появление блоков, шапка, вкладки «Куда позвать»; `reviews.js` — полароиды-стопки
- `schedule.js` — **список выступлений** (даты, место, ссылка) — править тут
- `yura-widget.html` — мини-Юра (2D, зеркально, бьёт по струнам при звуке); спрайт `assets/images/yura-sheet.webp`
- `hero-repair.css/js` — старый вход (оставлены кусочки для интро)

## Решения (по просьбам Юры)
- **Палитра зафиксирована:** кремовый `#f2e6cf`, песочный `#cbb28b`/`#e6d2ad`, коричневый `#3b2a24`, приглушённый бирюзовый `#245e58`. Шрифты: Oswald (заголовки), Source Serif 4 (текст), Caveat (рукописное), Unbounded (только вход).
- Вход «Заходи, споём вместе»: на весь экран, без прокрутки, показывается при каждой загрузке. Лампа-прожектор на треноге включается, настоящая гитара Юры падает ему в кулак, левая рука лежит на корпусе, кадр замирает, нажатие на гитару открывает сайт.
- Главная: Юра справа на любом экране; блок «Привет, я Юра»; «Куда позвать» — вкладки поводов; видео вертикальные; афиша; отзывы-полароиды (две стопки, перекладываются дугой, тянутся пальцем); «Сыграем у вас?».
- Мини-Юра: **2D спрайт** (3D-версию Юра отверг — «не похож»), отзеркален, гриф слева.
- Скорость: видео/звук грузятся только по нажатию ▶, картинки WebP, шрифты Caveat WOFF2, шрифты Google не блокируют отрисовку.

## Как делалось интро (если нужно переделать)
1. `cutout_amp.py` — вырезает Юру на комбике и гитару из белого фона (фото 1024×765)
2. `split_guitar.py` — вырезает **настоящую гитару с исходного фото** (`yura-hero-holding-guitar-v1.png`), достраивает ногу
3. `guitar_v2.py` — чистит гитару, восстанавливает плечо деки, ставит по масштабу 0,41, вырезает левую руку (контур `hand_poly.py`)
4. `gen_stage.py` — рисует лампу (SVG) и собирает сцену; `inject.py` — вставляет в `index.html`
Нужен Python с `pillow numpy opencv-python-headless`.

## Открытые вопросы
- Нет стоящего в полный рост кадра Юры для главного экрана после входа — стоит фото в кресле
- Фото для интро 1024×765: на ретине слегка мягкое, нужен оригинал побольше
- Гитара падает по CSS-анимации; на реальном телефоне по сети не проверялось
- Мини-Юра на телефоне может закрывать кнопки — его можно перетащить
- Публикации нет: проект полностью локальный
